# Lumo showcase site

Static landing page for the Lumo Discord bot. Plain HTML/CSS/JS with no build step.

- `index.html`: short landing page (hero with mock cluster, fact band, four highlights, Premium teaser, CTA).
- `features.html`: alternating feature rows with the Discord-style illustrations, plus a small-features grid. `commands.html`: every slash command with search and filters (cards come from the bot's source).
- `premium.html`: Get Premium (price, free vs Premium table, how to buy, renewals). `faq.html`: FAQ accordions with FAQPage JSON-LD.
- `styles.css`, `script.js`: styling plus command search, filter, click-to-copy and scroll reveal.
- `assets/lumo-holiday.js`: seasonal themes (Halloween in October, Thanksgiving from November 1 through the Sunday after Thanksgiving, Christmas from the Monday after that through December 31, by the visitor's own date; or picked under **Seasonal** in the appearance menu). It swaps the robot pictures for `assets/robot/<theme>/*.webp` and `assets/logo-<theme>.webp` (Lumo in a witch hat, a pilgrim hat or a Santa hat) and draws a few slow particles behind the page. The dashboard uses the same file.
- `terms.html`, `privacy.html`: Terms of Service and Privacy Policy (linked from the footer; use these URLs in the Discord Developer Portal).
- `getting-started.html`: five-step setup guide. `changelog.html`: user-facing highlights from the bot CHANGELOG. `404.html`: custom not-found page. All generated by the site generator.
- `assets/logo.webp`: the Lumo logo mark (the robot profile picture). `assets/robot/*.webp`: the robot mascot poses (transparent, lazy-loaded WebP). `favicon.ico`, `favicon-*.png`, `apple-touch-icon.png`, `android-chrome-*.png` and `og-image.png` (1200x630 share card) are generated from the mascot artwork. `sitemap.xml`, `robots.txt`, `site.webmanifest` for search/install metadata.

The "Add to Discord" buttons (nav on every page, plus the home hero and closing call-to-action) use the OAuth invite
(`https://discord.com/oauth2/authorize?client_id=1545140271073722378&permissions=309576723664&scope=bot+applications.commands`).
"Join our support server" links go to `https://discord.gg/KZjebts36C`. "Message Ori" links open the owner's Discord profile (`https://discord.com/users/1022200760018161684`) for questions and Premium codes.

To host on GitHub Pages, put these files in a repo (or a `docs/` folder) and enable Pages for that branch/folder.
The mock Discord panels are illustrations in HTML/CSS, not screenshots. No tracking scripts.

## Languages

The English pages at the root are the source. `/es/`, `/pt-br/` and `/ja/` are built from them with
`python3 i18n/build.py` (translations in `i18n/<code>.json`, keyed by the English text). Run it after editing an
English page, then `python3 i18n/build.py --check` should print no "would change" line. It also adds the hreflang
links, the language switcher and the cache-busting versions to every page, and the language URLs to `sitemap.xml`.
`privacy.html` and `terms.html` stay English and say so in all four languages. Changelog entries stay English.
